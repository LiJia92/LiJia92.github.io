正则表达式引擎在处理重复结构时，会使用栈来跟踪匹配状态：

  • 原始正则的 (\.\d+)* 会为每个匹配的子组创建栈帧
  • 当输入超长时（如包含上百个版本号段），栈内存会被耗尽
  • 非捕获组 (?:\.\d+)* 不会创建额外栈帧，大幅减少内存消耗
